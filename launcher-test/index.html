Ajouter un raccourci

Ajoutez cette page avant d’ouvrir ARIA. Vérifiez que l’icône proposée est le A avec son étoile.

  • Android / Chrome : menu ⋮ → Ajouter à l’écran d’accueil ou Installer, selon ce qui est proposé.
  • iPhone / Safari : Partager → Sur l’écran d’accueil. Le nom court proposé est ARIA.
  • Mac / Safari : Partager ou Fichier → Ajouter au Dock, si disponible.
  • Windows / Chrome ou Edge : menu du navigateur → créer un raccourci ou installer ce site si proposé.

ARIA s’ouvre ensuite sur Google Apps Script. Les contrôles du navigateur peuvent réapparaître et une connexion Google peut être nécessaire.
