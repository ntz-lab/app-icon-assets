# ARIA app icons

Public icon assets for the ARIA TEST web app. These images are product artwork and contain no application code, credentials, or customer data.

Files in `/favicon/` are exported from the validated source assets. To replace the artwork, publish new files under versioned names (for example `favicon-48-v2.png`), validate the public HTTPS URL, then update the single `ARIA_APP_IDENTITY.iconUrl` setting in the Apps Script source and its documentation. Versioned filenames avoid stale browser caches.
