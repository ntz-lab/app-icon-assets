# Application icon assets

Public icon assets for the application. These images are product artwork and contain no application code, credentials, or customer data.

Files in `/favicon/` are exported from the validated source assets. To replace the artwork, publish new files under versioned names (for example `favicon-48-v2.png`), validate the public HTTPS URL, then update the single application icon URL setting in the application source and its documentation.

Versioned filenames avoid stale browser caches.
